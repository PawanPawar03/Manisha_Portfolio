# Manisha Avinash Patke - Professional Portfolio

Modern, interactive, and responsive portfolio website for **Manisha Avinash Patke** – Specialist in Tally Prime, Advanced Excel, Financial Accounting, Data Management, and Office Operations.

![Portfolio Preview](profile.jpg)

## 🌟 Key Features

- **Executive Theme**: Dark and Light mode toggle with smooth theme transition.
- **Interactive Live Practical Simulator**:
  - **GST & Invoice Voucher Calculator**: Computes CGST, SGST, Subtotal, and Net Payable dynamically for Tally Prime practical demonstration.
  - **Interactive Excel Spreadsheet Dashboard**: Filterable and searchable ledger table with live calculation of Debits, Credits, and Trial Balance matching.
  - **Live Typing Speed Tester**: Real-time WPM and accuracy testing with color-coded feedback (MSCE English 40 WPM & Marathi 30 WPM certified).
- **Categorized Skills Matrix**: Filter by Accounting & Finance, Advanced Excel, Office Computing, and Typing with animated skill meters.
- **Academic & Certifications Timeline**: Complete education records (M.A., B.A. from SRTMU Nanded) and technical certifications (KLIC, MKCL, MSCE).
- **Direct Resume Download**: Integrated `Manisha_Avinash_Patke_Resume.pdf` download and print view.
- **Fast Contact Hub**: Direct WhatsApp link, 1-click copy for phone and email, and interactive inquiry form.

## 🛠️ Built With

- **HTML5**: Semantic markup, SEO-ready structure, KaTeX / Google Fonts.
- **CSS3**: Custom CSS variables, responsive grid, flexbox, glassmorphism, animated glow effects.
- **Vanilla JavaScript**: Zero external runtime dependencies, high-performance interactions.
- **Font Awesome 6**: Vector icons.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or host on GitHub Pages:

```bash
# Clone the repository
git clone https://github.com/PawanPawar03/Manisha_Portfolio.git

# Open the project
cd Manisha_Portfolio
start index.html
```
